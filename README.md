# Axion-Phonon Coupling in Magnetic Insulators

Code accompanying the paper **"Exact expression for the Berry connection in the projection gauge"** by Trey Cole and David Vanderbilt. 

## 📜 Paper
The `LaTeX` source code and a PDF of each version of the manuscript can be found in the [paper](/paper) folder. 

## 💻 Results 

The [axion_phonon](/axion_phonon/) folder contains the code used to generate the results in the paper.

The notebooks and scripts located in the [analysis](/analysis) folder use this code to generate the figures and tables in the paper.

The data is available at [Zenodo]().
