# Meeting 2026-10-07: progress since 2026-09-23

**Main result.** YIO's Berry curvature did not obey the crystal's magnetic symmetry. Two causes were found:
1. **WS tie tolerance (ours).** The Wigner–Seitz tie tolerance in our Wannier interpolation was too tight. Widening
   it cut the violation about 4× and fixed inversion completely, but the rotations stayed broken.
2. **A Quantum ESPRESSO bug.** What remained is a QE bug in the PAW part of the noncollinear GGA. It makes the DFT
   Hamiltonian itself non-symmetric, singling out one Ir atom. Patched QE restores the DFT symmetry about 100×.

All YIO DFT is now being recomputed with the patch. The earlier dθ values are superseded.

Details: `notes/bugs/README.md` (status table, one file per bug), `notes/log/` (dated notes).

---

## 1. The problem: YIO's Berry curvature is not symmetric

**Test.** Y2Ir2O7 (all-in-all-out) has 48 magnetic symmetry operations (base structure): rotations, mirrors and inversion, some combined with time
reversal (the group is written m-3m′). In the tables each operation class is given by its symbol (Cn = rotation by 360°/n about the axis in ⟨⟩,
I· = combined with inversion, ′ = combined with time reversal) and in words. For every operation g, the curvature must satisfy
Ω(gk) = det(R)·(−1 if g includes time reversal)·R Ω(k). We evaluate Ω at 7 generic k-points and report
the relative residual, max |Ω(gk) − predicted| / max |Ω|, for each part of the curvature:
- **internal:** built from H(R) only;
- **cross:** mixed H(R) / A(R) terms;
- **external:** built from the position matrix A(R).

A control operation that is *not* a symmetry of YIO (a 90° rotation about z combined with inversion, without time
reversal) gives ~199%, so the test discriminates.

**Base YIO, QE 7.6 + `new_ns_nc` fix, `.chk`-based A(R), WS tie tolerance 1e-5 Å (the setting before this work):**

| operation class | n | total | external |
|---|---|---|---|
| I (inversion) | 1 | 10.5% | 151% |
| C2 ⟨100⟩ (180° rotation about a cube axis) | 3 | 4.9% | 81% |
| I·C2 ⟨100⟩ (mirror perpendicular to a cube axis) | 3 | 8.5% | 131% |
| C2′ ⟨110⟩ (180° rotation about a face diagonal, with time reversal) | 6 | 5.7% | 92% |
| I·C2′ ⟨110⟩ (mirror perpendicular to a face diagonal, with time reversal) | 6 | 7.9% | 91% |
| C3 ⟨111⟩ (120° rotation about a body diagonal) | 8 | 6.1% | 86% |
| S6 = I·C3 ⟨111⟩ (120° rotation about a body diagonal, with inversion) | 8 | 6.6% | 92% |
| C4′ ⟨100⟩ (90° rotation about a cube axis, with time reversal) | 6 | 6.4% | 85% |
| S4′ = I·C4′ ⟨100⟩ (90° rotation about a cube axis, with inversion and time reversal) | 6 | 6.6% | 85% |
| **all 47, median (max)** | | **6.55% (12.3%)** | **89.6% (153%)** |

Internal median 2.25%, cross 36.5%. Before the `new_ns_nc` QE fix (2026-09-21), the floor was 4–14%. That fix improved
H(R) 2–4×, but the total got no better.

## 2. First fix: widening the Wigner–Seitz tie tolerance

**What the tolerance does.** A finite k-mesh fixes each hopping H(R) and position element A(R) only up to a lattice
translation of the supercell. The interpolation assigns each one to the shortest image. When two images are equally
long ("tied"), symmetry requires the weight to be split equally. Our code treated images as tied only if their
lengths agreed to **1e-5 Å**. But the Wannier centres are symmetric only to ~6e-4 Å, so many genuine ties went
unrecognized, and one image got all the weight. That broke inversion (14% of near-ties were inversion-inconsistent).

**The physically allowed range.** All ~34 M (orbital pair, R) entries × 27 images were measured:
- **Noise-broken ties:** excess distances up to **2.05e-3 Å** (consistent with the ~6e-4 Å centre noise).
- **Nothing in between:** no image at all with an excess in [2.05e-3, 2.12e-2) Å.
- **Genuinely different bonds:** start at **2.12e-2 Å**.

So any tolerance in [2.05e-3, 2.12e-2) Å gives the identical, symmetric fold. The code default was raised to 1e-3 on
2026-09-30. **5e-3** (inside the window) is recommended but not yet applied.

**Result, full group, median over 47 operations:**

| tolerance | total | external | internal | inversion total |
|---|---|---|---|---|
| 1e-5 (before) | 6.55% | 89.6% | 2.25% | 10.5% |
| 1e-3 | 1.57% | 25.9% | 1.06% | 0.24% |
| 5e-3 (in the window) | **1.55%** | **25.6%** | 1.06% | **0.18%** |

| class (median, 1e-5 → 5e-3) | total | external |
|---|---|---|
| I (inversion) | 10.5% → **0.18%** | 151% → **0.9%** |
| C2′ ⟨110⟩ (180° rotation about a face diagonal, with time reversal) | 5.7% → 0.90% | 92% → 17% |
| C3 ⟨111⟩ (120° rotation about a body diagonal) | 6.1% → 1.51% | 86% → 26% |
| C4′ ⟨100⟩ (90° rotation about a cube axis, with time reversal) | 6.4% → 1.55% | 85% → 26% |
| C2 ⟨100⟩ (180° rotation about a cube axis) | 4.9% → 1.76% | 81% → 31% |

**Conclusion:** about a 4× improvement for every operation, and inversion is fixed. The rotations still violate symmetry
at ~1.5% total / ~26% external. Since any tolerance in the window gives the same fold, **what's left is not
tie-breaking.**

**Axion response before and after the tolerance fix.** dθ/dQ in rad/Å for the three Γ₂⁻ (A₂ᵤ) displacement patterns.
Each is a finite difference between the base structure and the structure displaced by Q = 0.01 Å, on a
12×12×12 interpolation mesh. "Base end / displaced end" are the two one-sided estimates. All entries use the same
position matrix A(R): Jae-Mo's translationally invariant formula (`transl_inv_full_from_chk`), rebuilt from the
Wannier checkpoint, with the base and displaced structures folded on the same (base) Wigner–Seitz images. Only the
tie tolerance differs between the columns.

| displacement pattern | before (tolerance 1e-5 Å) | **after (tolerance 1e-3 Å)** | change | convergence, 10³ → 12³ mesh |
|---|---|---|---|---|
| mode 1 | −0.01752 / −0.01761 | **−0.01753 / −0.01760** | < 0.1% | 0.05% |
| mode 2 | +0.04593 / +0.04758 | **+0.04517 / +0.04668** | −1.7% / −1.9% | 0.07% |
| mode 3 | +0.1684 / +0.1775 | **+0.1689 / +0.1779** | +0.3% / +0.2% | 0.01% |

- **The tolerance fix barely moves dθ** (≤ 2%), although it cut the curvature symmetry violation about 4× and
  fixed inversion. The Brillouin-zone integral averages most of the pointwise asymmetry away.
- **The A(R) formula matters more than the tolerance.** At 1e-3 the `.mmn` formula from the same checkpoint
  (`right_centre_from_chk`) gives −0.01856 / −0.01864, +0.04387 / +0.04558, +0.1697 / +0.1787: 6% from Jae-Mo's for
  mode 1, 3% for mode 2, 0.5% for mode 3. Jae-Mo's formula is the production choice.
- **How the tolerance of each run is known:** the run files don't record it. Each run's stored base band gap was
  matched against the base Hamiltonian rebuilt at both tolerances (they differ by 7e-5 to 3e-4 eV at the
  minimum-gap k-points; the runs match one of them to < 1e-6 eV).
- **Superseded:** all of these come from the DFT with the QE bug of section 4 (base 192344, modes 192345–192347,
  run with QE 7.6 *with* the Hubbard-occupation (`new_ns_nc`) fix, but before the PAW GGA fix). They show the size
  and sign of the response; the production numbers are being recomputed now on the patched DFT (section 5). Mode 3's
  response is ~10× mode 1's, and modes 2 and 3 have the opposite sign to mode 1.

## 3. Tracing the rest: it's in the DFT, and it singles out Ir1

**The DFT eigenvalues already break the symmetry.** Comparing ε_n(k) with ε_n(gk) in the NSCF `.eig` (8³ mesh,
occupied bands):

| operations | max \|Δε\| |
|---|---|
| I (inversion) | 0.87 meV |
| the 12 operations that keep Ir1's body-diagonal axis fixed (−3m′ about Ir1's [111]) | 1.0–1.9 meV |
| all other 36 operations | **7.1–7.6 meV** |

- **Ir1 is singled out:** the on-site Hamiltonian of Ir1 (the Ir at the origin) is **12 meV** off Ir2–Ir4, which
  agree with each other to 0.3 meV.
- **The curvature residual tracks it:** per operation, the curvature residual follows the DFT asymmetry with
  correlation ≈ 0.9, for the internal, cross and external parts alike. In absolute terms all three are off by the
  same amount. External only *looked* worst because its scale is 25× smaller.
- **So A(R) is not a separate problem.**
- **But the SCF looks perfect:** all 48 operations found, all four Ir moments identical and along their body diagonals, and ρ, m,
  Hubbard ns and PAW occupations exactly symmetric.

**Isolating it (cluster NSCF tests from the same SCF save, 2026-10-05):**

| test | change | breaking |
|---|---|---|
| A | PAW `v_rad` bug fixed (in the NSCF only) | 7.6 meV, unchanged |
| B | old binary, different process count | 7.6 meV, unchanged |
| C | fully fixed SCF + NSCF (QE `v_rad` fix) | 4.8 meV, same pattern |
| L1 | no Hubbard U | 5.1–5.6 meV |
| L2 | atomic instead of ortho-atomic projectors | 4.3–4.5 meV |
| **L3** | **LDA instead of PBE** (L1 with `input_dft = 'pz'`) | **0.0 meV** |
| **L5** | GGA reference axis moved off Ir1 | **0.1–0.2 meV** |

The problem is in QE's noncollinear GGA, and it follows the "reference axis".

**How the L tests were run.** Each is an NSCF only, at the four L points, starting from the converged PBE+U SCF
of run 193145 (same PBE PAW datasets). L0 reproduces C. L1 drops the `HUBBARD` card, L2 switches to `atomic`
projectors, and L3 is L1 with `input_dft = 'pz'` in `&SYSTEM`. QE then overrides the functional of the PAW
datasets ("XC functional enforced from input: PZ") and builds the NSCF potential from the stored PBE density with
LDA (Perdew–Zunger) exchange-correlation. So L3 is not a self-consistent LDA calculation: same density, same
datasets, only the functional that turns the density into a potential is changed. That is enough for this
question. The asymmetry is generated when the potential is built from a symmetric density, and with LDA, which uses
no density gradients, it vanishes exactly. L5 keeps PBE and only moves the reference axis (a 0.01 starting moment
on Y along +z).

## 4. The bug (QE, PAW one-centre noncollinear GGA)

**How QE builds the GGA input.** PBE needs spin-up and spin-down densities, n↑,↓ = ½(n ± s·|m|), at every point,
with s = ±1. QE has two modes:
- **Collinear magnets** (all moments ∥ or anti-∥ one axis, e.g. MnBi2Te4): one global axis `ux`, with
  s = sign(m·ux). "Up" means +ux everywhere.
- **Noncollinear magnets** (e.g. YIO's all-in-all-out): no axis, s = +1. "Up" means along the local m at each point
  (the eigenvalues of the spin-density matrix).

**What goes wrong in YIO:**
1. **QE leaves the axis set.** At startup it sets `ux` to the first magnetic atom's moment (**Ir1**). It finds that
   YIO's moments aren't parallel and correctly switches to the noncollinear mode (`lsign = .false.`), but it never
   clears `ux`.
2. **Only the PAW part uses it.** The plane-wave GGA follows the mode. The **PAW part** (inside a sphere around each
   atom) doesn't check it, and uses s = sign(m·ux) with Ir1's axis anyway (`paw_onecenter.f90`, line ~2340).
3. **That creates jumps.** Wherever the local m crosses the plane perpendicular to Ir1's axis while |m| is finite,
   n↑ jumps (e.g. 0.3 ↔ 0.7 for n = 1, |m| = 0.4). PBE differentiates n↑, so the jump becomes a spurious potential.
4. **Equivalent atoms become inequivalent.** The plane belongs to Ir1, so it cuts Ir1's magnetization texture
   symmetrically but Ir2–Ir4 and the O atoms at unrelated angles. Equivalent atoms get different potentials, and only
   the 12 operations that keep Ir1's axis fixed survive.
5. **Why it was hidden:** the SCF symmetrizes the density, occupations and PAW coefficients every iteration, so all
   printed SCF quantities are perfect. The NSCF (used for Wannier90) rebuilds the PAW potential once without
   symmetrizing, so the breaking passes into the Wannier model, the curvature and dθ.

**Who it affects:** noncollinear magnetic + GGA + PAW calculations whose starting moments aren't all (anti)parallel.
**MnBi2Te4 is not affected:** collinear Mn ±z, so the global-axis mode is used as intended (all its runs print "Fixed
quantization axis for GGA: 0 0 1").

**Fix:** in the PAW code, use s = sign(m·ux) only in the collinear mode and s = 1 otherwise, the same rule as the
plane-wave part. Built on the cluster as `~/q-e-segnifix` (pw.x md5 `e270b05b`). The code is unchanged on QE develop,
so it is probably worth reporting upstream.

## 6. How the checks were done

Full write-up with scripts: `notes/log/2026-10-07_validation_methods_and_nk10_mesh.md` §3-4.

**Why the SCF density is symmetric but the NSCF eigenvalues are not.** The density is symmetric because QE enforces
it, not because the Hamiltonian is.
- **The potential doesn't respect symmetry:** the step from sphere occupations to the PAW potential term D_ij uses
  the fixed axis `ux`, which doesn't rotate with the crystal. Exactly symmetric occupations therefore still give Ir1
  a D_ij that isn't the image of Ir2-4's.
- **The SCF averages it away:** every SCF iteration symmetrizes ρ, m, ns and becsum *and* averages D_ij over the 48
  operations. The SCF Hamiltonian is symmetric, but it contains the averaged spurious term, so the SCF state is
  shifted (and must be rerun).
- **The NSCF keeps it:** the NSCF builds D_ij once and never averages it, so ε(k) ≠ ε(gk).

**`new_ns_nc` fix (#7), validated five ways:**
1. **Python port of QE's symmetrizer** with run 178382's operation data. QE's exact AIAO occupations are invariant
   under all 48 operations (6e-15). The unpatched symmetrizer still changes them (|m| 3 → 1); patched, it returns
   them unchanged (1e-15).
2. **Patched vs unpatched pw.x on identical input** (same seeds, so identical raw occupations). Ir moment spread
   2.5% and tilt 0.7° unpatched, against 0.00% / 0.00° patched.
3. **The cluster production input:** patched, the four Ir are equal and on-axis at every iteration; unpatched, the
   Hubbard moment collapses. Unconverged (20 iterations).
4. **A 4-Fe minimal case for upstream:** 7.9-9.6% spread unpatched, 0.00% patched.
5. **The converged SCFs' stored data:** ρ and m covariant to 1e-15 in G-space (fractional-translation phases and
   the axial-vector rule included), ns to 3e-10 including phases, becsum magnitudes to 1e-14.

These show the SCF state is symmetric. They can't detect #16, which the SCF hides.

**DFT eigenvalue check (#16).** On the NSCF's full 8×8×8 mesh (`nosym`), compare ε_n(k) with ε_n(gk) (−gk for
operations that include time reversal), bands 1-156. gk always lands on the grid:
- **Γ-centred grid:** every k is n/8.
- **Lattice symmetries:** each of the 48 operations is a symmetry of the fcc lattice, so in reduced coordinates it is
  an integer matrix (checked: all 48 integer to 1e-17).
- **So each operation permutes the 512 points,** using ε(k+G) = ε(k). Fractional translations don't move k.
- **This would fail** for a shifted Monkhorst-Pack grid.

**"On-site levels" of Ir1.**
- **The block:** each Ir has 10 Wannier functions (d × spinor). The eigenvalues of that atom's 10×10 on-site
  block H(R=0) are its local d levels: the trigonal crystal field, SOC and exchange.
- **The test:** symmetry maps Ir1's set onto Ir2's, so the two spectra must be equal whatever the gauge.
- **The result:** Ir2-4 agree to 0.3 meV, and Ir1 is 12 meV off.

**Isolating the cause.** NSCF tests changing one thing at a time, on 60 k-points built as complete symmetry orbits
(so every gk is in the set).

**Validating the fix (the patched test run).** It is the unpatched test run with only the binary changed: the same SCF save and k-points, a
byte-identical input, and eigenvalues compared at full precision. This validates the NSCF Hamiltonian; the
production reruns validate the full chain.

**Curvature tables.**
- **k-points:** 7 random generic, off-grid k-points (fixed seed), on the Wannier-interpolated model.
- **Comparison:** ω(gk) against ±det(R)·R·ω(k), per curvature part.
- **Calibration:** the non-symmetry control (90° rotation about z with inversion, no time reversal) gives ~199%.
